# Security Awareness Survey

This folder documents the survey component of The 360° Cyber Shield.

## Reported indicators

The project notes report a sample size of 50 and these provisional values:

| Indicator | Reported value |
|---|---:|
| Interaction with unverified phishing links | 24% |
| Password reuse | 20% |
| Use of unsecured public Wi-Fi | 46% |
| Postponement of security updates | 48% |
| Willingness to use untrusted USB media | 20% |
| No MFA enabled | 14% |

These figures must be checked against the original response export. The denominator may differ between questions because of skipped responses.

## Required methodology details

Document survey dates, recruitment and eligibility, participant consent, exact question wording, response options, valid response counts, missing data, and calculation method. Keep participant identities private.

## Important distinction

A self-reported survey response is not the same as an observed Gophish campaign action. Do not combine survey percentages with campaign click or submission rates.
