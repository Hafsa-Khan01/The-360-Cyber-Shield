# Evidence

Place only genuine, authorized, sanitized project evidence in this directory.

Suggested organization:

- Gophish/ — campaign configuration summaries and sanitized aggregate exports
- Acunetix/ — sanitized scan summaries and finding evidence
- Wazuh/ — agent status, decoder tests, rule matches, and alert records
- Survey/ — anonymized aggregate charts and methodology evidence
- System/ — resource measurements and sanitized OOM diagnostics

Do not commit raw participant data, real credentials, SMTP settings, API tokens, session cookies, private keys, unredacted scan output, or sensitive infrastructure details.

For each artifact, add a short note with date, tool version, test scope, what it demonstrates, and any limitations. Never fabricate screenshots or test output.
